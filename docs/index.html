Hand Harmoniser

Sing into a mic while your hands, tracked by the webcam, pick a chord. The app pitch-shifts your live voice onto the chord tones.

Download for Apple Silicon Download for Intel

Looking up the latest macOS build…

xattr -cr "/Applications/Hand Harmoniser.app"
macOS will say the app is “damaged”. It isn’t — Gatekeeper blocks unsigned downloads. Drag the app to Applications, run the line above in Terminal, then open it. Needs camera and microphone.
  • Left hand: finger count + palm/back = chord root
  • Right hand: finger count = quality, height = harmony volume
